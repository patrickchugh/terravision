# AWS Architecture Diagram Generator

TerraVision generates AWS architecture diagrams with the official AWS icon set. Resources are drawn inside their region, availability zone, VPC, subnet and security group. Describe the architecture to an AI assistant, write a short JSON graph, or point it at your Terraform code. It is free, open source and runs on your own computer.

![AWS serverless event-driven architecture diagram generated by TerraVision](https://raw.githubusercontent.com/patrickchugh/terravision/main/examples/graphs/aws-serverless-event-driven.png)

## How do I generate an AWS architecture diagram?

**With an AI assistant.** Connect TerraVision to Claude, ChatGPT, GitHub Copilot or Cursor ([setup](ai-assistants.md)) and ask:

> Draw an AWS three-tier app: React on CloudFront, ECS Fargate behind an ALB in two AZs, SQL Server on RDS Multi-AZ

**From a JSON graph.** No Terraform and no cloud credentials needed. Start from the worked example [three-tier-web.tvg.json](https://github.com/patrickchugh/terravision/blob/main/examples/graphs/three-tier-web.tvg.json):

```bash
pipx install terravision
terravision draw --source three-tier-web.tvg.json --format svg
```

**From Terraform.** The diagram shows what `terraform plan` says the code deploys:

```bash
terravision draw --source ./infrastructure
```

## Which AWS services are supported?

TerraVision supports 385 AWS resource types, named exactly as in the Terraform provider, so there is no separate icon vocabulary to learn. The full list is on the [Node types](node-types.md) page.

## Does it follow the official AWS diagram style?

Yes. It uses the official AWS architecture icons and draws containers the way AWS reference architectures do. Resources are drawn inside their region, availability zone, VPC, subnet and security group. Numbered request flows and connection labels can be added with [annotations](annotations.md).

## What can I export?

PNG, SVG, PDF and other Graphviz formats, an editable draw.io file that also opens in Lucidchart, and a self-contained interactive HTML page with pan, zoom and search.

## Does it need access to my AWS account?

No. TerraVision never calls a cloud API and your code stays on your machine. See [Security and Privacy](faq.md#security-and-privacy).
