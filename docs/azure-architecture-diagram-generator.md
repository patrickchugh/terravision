# Azure Architecture Diagram Generator

TerraVision generates Azure architecture diagrams with the official Azure icon set. Resources are drawn inside their region, resource group, virtual network, subnet and zone. Describe the architecture to an AI assistant, write a short JSON graph, or point it at your Terraform code. It is free, open source and runs on your own computer.

![Azure three-tier architecture diagram generated by TerraVision](https://raw.githubusercontent.com/patrickchugh/terravision/main/examples/graphs/azure-three-tier.png)

## How do I generate an Azure architecture diagram?

**With an AI assistant.** Connect TerraVision to Claude, ChatGPT, GitHub Copilot or Cursor ([setup](ai-assistants.md)) and ask:

> Draw an Azure three-tier web app: Front Door with WAF, Application Gateway, Container Apps across two zones, Azure SQL via private endpoint

**From a JSON graph.** No Terraform and no cloud credentials needed. Start from the worked example [azure-three-tier.tvg.json](https://github.com/patrickchugh/terravision/blob/main/examples/graphs/azure-three-tier.tvg.json):

```bash
pipx install terravision
terravision draw --source azure-three-tier.tvg.json --format svg
```

**From Terraform.** The diagram shows what `terraform plan` says the code deploys:

```bash
terravision draw --source ./infrastructure
```

## Which Azure services are supported?

TerraVision supports 245 Azure resource types, named exactly as in the Terraform provider, so there is no separate icon vocabulary to learn. The full list is on the [Node types](node-types.md) page.

## Does it follow the official Azure diagram style?

Yes. It uses the official Azure architecture icons and draws containers the way Azure reference architectures do. Resources are drawn inside their region, resource group, virtual network, subnet and zone. Numbered request flows and connection labels can be added with [annotations](annotations.md).

## What can I export?

PNG, SVG, PDF and other Graphviz formats, an editable draw.io file that also opens in Lucidchart, and a self-contained interactive HTML page with pan, zoom and search.

## Does it need access to my Azure account?

No. TerraVision never calls a cloud API and your code stays on your machine. See [Security and Privacy](faq.md#security-and-privacy).
